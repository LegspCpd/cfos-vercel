# 使用说明

## 首次登录

1. 访问你的域名
2. 点 **"使用 GitHub 登录"** / **"使用 Google 登录"** / **"使用 Microsoft 登录"** 或注册账号
3. 第一个账号是管理员（或 `ADMIN_USERNAME` 指定的）

### OAuth 首次登录需完善资料

通过 **GitHub / Google / Microsoft** 首次登录创建的新账号，会先进入 **完善资料** 页：

1. **设置用户名**（必填，默认填第三方用户名）
2. **设置密码**（必填，之后可用"邮箱+密码"登录）
3. **人机验证**（配置了 Turnstile/reCAPTCHA 时强制）
4. **绑定邮箱**（可选，绑了才能改邮箱 / 注销）

未完善前无法进入主界面，完善后自动进入。

## 绑定邮箱 / 更改邮箱 + 邮箱密码登录

无论你是用 GitHub / Google / Microsoft 还是密码注册，都可以**绑定邮箱并设置密码**，之后就能用"邮箱 + 密码"直接登录：

- **首次绑定**（账号还没有邮箱时，如 OAuth 完善资料时跳过了）：进入 **个人设置 → 邮箱**，填邮箱 → 发验证码 → 填验证码 + 设置登录密码 → 绑定
- **更改邮箱**（账号已有邮箱时）：个人设置 → 邮箱 → 点 **"更改邮箱"**：
  1. 输入**原邮箱** → 发验证码到原邮箱 → 填验证码（验证所有权）
  2. 输入**新邮箱** → 发验证码 → 填验证码
  3. 通过人机验证 → 提交后更改成功
- 邮箱板块底部还有 **"点我申诉"**：可提交申诉 / 反馈工单给管理员

下次登录时，在登录框直接输入**邮箱 + 密码**即可（登录框已支持输入邮箱或用户名）。

## 构建第一个应用

1. 首页输入框输入："帮我做一个计算器"
2. 回车，自动创建 workspace 并让 agent 构建
3. 编辑器查看代码，右侧实时预览
4. 继续和 agent 对话修改

## 核心功能

### 工作区（Workspace）
- 多文件代码编辑器（Monaco）
- 文件树：新建/删除/设为入口
- 实时预览（iframe）
- 自动保存（含"未保存"脏点提示、agent 修改标记）

### 文件历史与回滚
- 每次修改文件都会自动记录历史版本
- 编辑器顶栏点 **历史** → 选择某个版本 → 一键恢复

### AI Agent
- 用自然语言构建/修改应用
- 支持 markdown 输出
- 会参考你上传的上下文文档
- 对话记录自动保存，刷新不丢失

### 文件分享
- 上传到 R2，生成带有效期链接
- 下载走 R2 直链

### 蓝图（Blueprints）
- 每个工作区可**导出**为 `.gadget.json` 归档
- 顶部 **导入蓝图** 可把归档恢复为一个新工作区
- 点**复制链接**会生成**公开蓝图链接**，他人无需登录即可预览并复制代码

### 收藏工作区
- 工作区卡片右上角星标即可收藏
- 支持按"全部 / 收藏"筛选

### 外部连接
- 连接 GitHub，agent 可读取你的仓库

### 上下文文档库
- 上传参考文档，agent 构建时会读取
- 支持新建 / 查看 / 编辑 / 删除

## 管理后台

管理员登录 → 左侧 **Admin**：

- 统计数据
- 站点设置（名称/标语/横幅/页脚/默认模型/agent 指令）
- 注册开关、人机验证、品牌图标
- AI Provider
- Cloudflare Access 状态
- **操作日志入口**（完整日志在左侧"操作日志"）

## 操作日志（/admin/audit）

左侧菜单 **"操作日志"**（需 `admin.access` 权限）集中展示所有日志：

- **登录**：时间、用户、**IP 地址**（含失败尝试）
- **Agent 运行**：工作区上的 Agent 操作
- **AI 调用**：每次调用并记录 **token 用量**

## 工单管理（/admin/tickets）

左侧菜单 **"工单"**（需 `tickets.manage` 权限）：

- 查看所有用户提交的工单（反馈 / 申诉 / 更改邮箱 / 其他）
- 按状态筛选（待处理 / 处理中 / 已关闭）
- 查看详情：提交人、邮箱、**IP 地址**、内容
- **修改状态** + **回复用户**

> 用户提交工单时会过人机验证，并自动**邮件通知所有管理员**，邮件内含处理链接。

## 注销账号

在 **个人设置 → 注销账号**：

1. 填绑定邮箱 → 发送验证码
2. 填验证码 + **人机验证** → 提交
3. 进入 **4–7 天冷静期**，期间可随时**取消**
4. 到期自动**永久删除**账号及所有数据，**邮箱/用户名释放，可重新注册**

## 自定义网站背景

在 Vercel 环境变量添加 `NEXT_PUBLIC_BEIJIN`（值为背景图 URL）并 Redeploy，全站显示背景图，每次刷新重新请求。

## 用户分组与权限

系统用**用户分组**控制功能权限，**分组完全决定权限**。用户移入哪个分组，就获得该组的功能。

功能权限项（新建分组时勾选）：

- **工作区 & AI agent**：创建/编辑/删除工作区
- **文件分享/蓝图**：R2 分享、蓝图导出导入
- **上下文文档库**：上传/编辑参考文档
- **外部连接**：GitHub/Google/GitLab
- **管理后台访问**（管理类）：进入管理后台
- **用户管理**（管理类）：管理用户和分组

> 管理类功能（`admin.access`、`admin.users`）只有被分到"超级管理员"或勾了这些权限的分组的用户才能看到。普通用户看不到管理入口。

内置分组：
- **超级管理员**：拥有全部权限
- **普通用户**：只有工作区 & AI

第一个用户自动进入超级管理员分组；`ADMIN_USERNAME` 指定的用户也进超级管理员分组。

### 用户管理（/admin/users）
有 `admin.users` 权限的用户可在左侧 **用户管理** 页面：
- 新建用户（用户名/显示名/密码/邮箱/分组）
- 编辑用户：改密码、改邮箱、移动分组
- 删除用户
- 新建分组（勾选功能权限）、编辑分组权限、删除分组

## 分析页（/analytics）

所有登录用户都能在左侧 **分析** 页面查看详细统计：

- **个人卡片**：工作区数、文件数、今日登录次数、今日 AI 调用次数、今日 Token 用量
- **今日登录记录**：你今天登录用的 **IP 地址** + 时间

管理员额外看到**全站今日概览**：今日登录总数、活跃用户、AI 调用、Token 总量，以及**今日登录 IP 分布**（Top 10 条形图）。
