# 使用说明

## 首次登录

1. 访问你的域名
2. 点 **"使用 GitHub 登录"** / **"使用 Google 登录"** 或注册账号
3. 第一个账号是管理员（或 `ADMIN_USERNAME` 指定的）

## 绑定邮箱 + 邮箱密码登录

无论你是用 GitHub / Google 还是密码注册的账号，都可以**绑定邮箱并设置密码**，之后就能用"邮箱 + 密码"直接登录：

1. 登录后进入 **个人设置**（Profile）
2. 找到 **绑定邮箱** 区块
3. 填一个可收验证码的邮箱 → 点 **发送验证码**
4. 输入验证码 + 设置一个登录密码 → 点 **绑定邮箱**
5. 下次登录时，在登录框直接输入**邮箱 + 密码**即可（登录框已支持输入邮箱或用户名）

## 构建第一个应用

1. 首页输入框输入："帮我做一个计算器"
2. 回车，自动创建 workspace 并让 agent 构建
3. 编辑器查看代码，右侧实时预览
4. 继续和 agent 对话修改

## 核心功能

### 工作区（Workspace）
- 多文件代码编辑器（Monaco）
- 文件树：新建/删除/设为入口
- 实时预览（iframe）
- 自动保存（含"未保存"脏点提示、agent 修改标记）

### 文件历史与回滚
- 每次修改文件都会自动记录历史版本
- 编辑器顶栏点 **历史** → 选择某个版本 → 一键恢复

### AI Agent
- 用自然语言构建/修改应用
- 支持 markdown 输出
- 会参考你上传的上下文文档
- 对话记录自动保存，刷新不丢失

### 文件分享
- 上传到 R2，生成带有效期链接
- 下载走 R2 直链

### 蓝图（Blueprints）
- 每个工作区可**导出**为 `.gadget.json` 归档
- 顶部 **导入蓝图** 可把归档恢复为一个新工作区
- 点**复制链接**会生成**公开蓝图链接**，他人无需登录即可预览并复制代码

### 收藏工作区
- 工作区卡片右上角星标即可收藏
- 支持按"全部 / 收藏"筛选

### 外部连接
- 连接 GitHub，agent 可读取你的仓库

### 上下文文档库
- 上传参考文档，agent 构建时会读取
- 支持新建 / 查看 / 编辑 / 删除

## 管理后台

管理员登录 → 左侧 **Admin**：

- 统计数据
- 站点设置（名称/标语/横幅/页脚/默认模型/agent 指令）
- 注册开关、人机验证、品牌图标
- AI Provider
- Cloudflare Access 状态
- 审计日志

## 用户分组与权限

系统用**用户分组**控制功能权限，**分组完全决定权限**。用户移入哪个分组，就获得该组的功能。

功能权限项（新建分组时勾选）：

- **工作区 & AI agent**：创建/编辑/删除工作区
- **文件分享/蓝图**：R2 分享、蓝图导出导入
- **上下文文档库**：上传/编辑参考文档
- **外部连接**：GitHub/Google/GitLab
- **管理后台访问**（管理类）：进入管理后台
- **用户管理**（管理类）：管理用户和分组

> 管理类功能（`admin.access`、`admin.users`）只有被分到"超级管理员"或勾了这些权限的分组的用户才能看到。普通用户看不到管理入口。

内置分组：
- **超级管理员**：拥有全部权限
- **普通用户**：只有工作区 & AI

第一个用户自动进入超级管理员分组；`ADMIN_USERNAME` 指定的用户也进超级管理员分组。

### 用户管理（/admin/users）
有 `admin.users` 权限的用户可在左侧 **用户管理** 页面：
- 新建用户（用户名/显示名/密码/邮箱/分组）
- 编辑用户：改密码、改邮箱、移动分组
- 删除用户
- 新建分组（勾选功能权限）、编辑分组权限、删除分组

## 分析页（/analytics）

所有登录用户都能在左侧 **分析** 页面查看个人使用统计：工作区数量、文件总数、最近活跃、最近的工作区列表。

## 移动端

- 侧边栏自动收起到菜单按钮
- 文档站适配手机
- 推荐在手机浏览器用"添加到主屏幕"
