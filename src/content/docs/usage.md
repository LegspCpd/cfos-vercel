# 使用说明

## 首次登录

1. 访问你的域名
2. 点 **"使用 GitHub 登录"** / **"使用 Google 登录"** 或注册账号
3. 第一个账号是管理员（或 `ADMIN_USERNAME` 指定的）

## 构建第一个应用

1. 首页输入框输入："帮我做一个计算器"
2. 回车，自动创建 workspace 并让 agent 构建
3. 编辑器查看代码，右侧实时预览
4. 继续和 agent 对话修改

## 核心功能

### 工作区（Workspace）
- 多文件代码编辑器（Monaco）
- 文件树：新建/删除/设为入口
- 实时预览（iframe）
- 自动保存（含"未保存"脏点提示、agent 修改标记）

### 文件历史与回滚
- 每次修改文件都会自动记录历史版本
- 编辑器顶栏点 **历史** → 选择某个版本 → 一键恢复

### AI Agent
- 用自然语言构建/修改应用
- 支持 markdown 输出
- 会参考你上传的上下文文档
- 对话记录自动保存，刷新不丢失

### 文件分享
- 上传到 R2，生成带有效期链接
- 下载走 R2 直链

### 蓝图（Blueprints）
- 每个工作区可**导出**为 `.gadget.json` 归档
- 顶部 **导入蓝图** 可把归档恢复为一个新工作区
- 点**复制链接**会生成**公开蓝图链接**，他人无需登录即可预览并复制代码

### 收藏工作区
- 工作区卡片右上角星标即可收藏
- 支持按"全部 / 收藏"筛选

### 外部连接
- 连接 GitHub，agent 可读取你的仓库

### 上下文文档库
- 上传参考文档，agent 构建时会读取
- 支持新建 / 查看 / 编辑 / 删除

## 管理后台

管理员登录 → 左侧 **Admin**：

- 统计数据
- 站点设置（名称/标语/横幅/页脚/默认模型/agent 指令）
- 用户管理（删除/提权）
- AI Provider
- Cloudflare Access 状态
- 审计日志

## 移动端

- 侧边栏自动收起到菜单按钮
- 文档站适配手机
- 推荐在手机浏览器用"添加到主屏幕"
