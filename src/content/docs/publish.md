# 一键静态发布

> 工作区顶栏的 **发布** 按钮，可以把整个工作区构建成**纯静态网站**并生成一个公开链接（`/p/<token>`），无需任何外部部署服务。适合把做好的应用分享给任何人查看，就像打开一个网页一样。

## 使用方法

1. 打开工作区 → 右上角 **发布**（工作区工具栏）
2. 点击 **发布** 按钮
   - 系统会把 `index.html` + `style.css` + `app.js` 等文件**内联打包**成单个自包含 HTML（CSS/JS 直接嵌入，不依赖外部文件）
   - 生成一个不可猜测的随机 token 链接
3. 复制链接发给别人，或点 **打开链接** 直接预览

**管理**：

- **重新发布**：修改代码后点"重新发布"，链接不变，内容更新
- **取消发布**：删除已发布的站点，旧链接立即返回 404
- 每次发布记录文件数与更新时间

## 链接格式

```
https://你的域名/p/<随机token>
```

token 为 128 位随机数（base64url），**不可猜测、不可枚举**；不知道 token 的人无法访问该页面。

## 适用场景

- 快速分享演示 / 作品给客户或朋友（无需对方登录）
- 把工作区生成的网页应用发布成"产品页"
- 临时上线一个静态落地页

## 限制

- 发布的是**静态快照**：只包含当前工作区文件，不含数据库、AI 等后端能力
- 仅支持 `index.html` 作为入口；`<link rel="stylesheet">` / `<script src>` 外链会被内联替代
- 每个工作区同时只有一个已发布版本（重新发布覆盖，取消发布删除）
- 已发布内容存储在**数据库**（`PublishedSite` 表），不依赖 R2 / Pages

## 谁可以发布

- 工作区**所有者**和**可编辑协作者**可以发布/取消发布
- 只读协作者只能查看发布面板状态
